- `emphasis` / `bold` 是**某个 line 或 text 里的一段原文子串**，画的时候这一段用强调色。

- `plate.mine` 1–3 项，`pct` 合计 100；`plate.guide` 固定三项（菜 40 / 谷薯 30 / 蛋白 30）。
  依据《中国居民膳食指南（2022）》平衡膳食餐盘：蔬菜与水果合计算一半、谷薯类多于鱼禽蛋豆；

- `tone` 只有 `veg`（#5F8A57）/ `carb`（#D9C08A）/ `protein`（#C4694A）三种。
- `exam.rows` 固定 3 行，顺序 蛋白质 / 蔬菜 / 全谷物；`tone` 是 `low` / `mid` / `ok`。
- `fix.rows` 固定 3 行，第一行 `strong: true`。
- `fix.ask.options` 固定 2 个。

## 五、没有照片时（`data.photo === null`）

- **P1**：不放照片。在 `0,0,1080,800` 画纸色块（bg 略深 `#F3EDE2`）+ 内缩 72 的 1px line 描边（虚线感用实线即可），
  中间放用户这一餐的原文（`data.mealText`，≤40 字，24px muted，最多 3 行，居中）——
  像一个「待补照片」的占位，不要画图标、不要画假图。
  meta 起点仍是 y=800 之后，版式其余完全不变。
- **P2**：去掉照片横条，双环整体上移到 ttl 下 44，其余不变（留白自然加大，不要拉伸环）。
- **P3**：人话卡去掉方图，卡片内边距改为 34 40，文字左对齐占满宽度。
- **P4**：不涉及照片。
- 无照片时**不要**出现任何「示例图」「AI 生成」字样。

## 六、文字兜底规则

- 每段文字先按给定字号排；只有**确实放不下**才依次：① 缩到 0.92 倍 → ② 减少 1 行（ellipsis）→ ③ 该行省略号截断。
- 允许的缩放下限：h1 不低于 68，ttl 不低于 50，P3 大数字不低于 84，P4 行主文不低于 34。
- 中文按字符折行（不拆标点在行首）；`fix.rows` 的主文最多 1 行（放不下就缩到 34 再截断）。
- 页面纵向排布：页头固定顶部；中间内容顺次向下；**贴底块**（P2 口径、P3 人话卡、P4 提问卡/CTA）从底往上定位，
  中间空出的余量留在最后一块之上，不要平均撒在行间。
